# Reaction Booster

対応サイトの「いいね」「フォロー」「スター」などのボタンをまとめてクリックする Chrome 拡張です。

## 対応サイトと操作

| サイト       | 操作                             |
| ------------ | -------------------------------- |
| Qiita        | いいね / ストック / フォロー     |
| Zenn         | いいね / ブックマーク / フォロー |
| note         | スキ / フォロー                  |
| Speaker Deck | star / follow                    |
| connpass     | ブックマーク / メンバー参加      |
| GitHub       | star                             |
| YouTube      | 高評価                           |

## 使い方

1. 対応サイトのページを開く
2. ツールバーの拡張アイコンをクリックするか、ショートカットキーを押す
   - Windows / Linux: `Shift+Ctrl+L`
   - Mac: `Shift+Control+L`
3. 成功時はバッジに `OK` が短く表示され、未対応サイトでは `N/A` が表示される

## インストール（開発用）

1. Chrome で `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このリポジトリの `packages/chrome-extensions/reaction-booster` フォルダを選択

## 副作用（確認ダイアログなし）

ショートカットまたはツールバー操作で**即実行**されます。拡張側に取り消し機能はありません。

| サイト   | 実行される操作                       |
| -------- | ------------------------------------ |
| connpass | ブックマーク + グループメンバー参加  |
| note     | スキ + 作者フォロー                  |
| Qiita    | いいね / ストック / フォロー（一括） |
| GitHub   | リポジトリ Star                      |

セレクタが陳腐化している場合、意図しない要素をクリックしたり、何も起きないことがあります（下記「注意」参照）。

## 注意

- 各サイトの DOM 構造に依存するセレクタを使っているため、サイト側の変更で動作しなくなることがあります
- 未対応サイトではツールバーバッジに `N/A` が表示されます
