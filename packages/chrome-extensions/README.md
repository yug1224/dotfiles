# Chrome Extensions

このディレクトリには、個人利用向けの Chrome 拡張機能を配置します。

## 拡張一覧

| 名前             | パス                                       | 説明                                                     |
| ---------------- | ------------------------------------------ | -------------------------------------------------------- |
| Reaction Booster | [`reaction-booster/`](./reaction-booster/) | 対応サイトのいいね・フォロー・スター等をまとめてクリック |

## Load unpacked（共通手順）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. 各拡張のルートフォルダ（例: `reaction-booster/`）を選択

拡張ごとの詳細は、各サブディレクトリの README を参照してください。
