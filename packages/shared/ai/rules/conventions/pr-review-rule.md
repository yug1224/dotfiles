# PR レビュールール（汎用）

重要度・出力骨格・敵対的検証の厚み（薄い／フル）は [`review-common-rule.md`](./review-common-rule.md) に従う。本ファイルは観点とテンプレート骨格を定義する。

## コンテキスト

- 対象リポジトリの `.cursor/rules/`（または同等）を動的に参照
- コミット／ブランチ規約が必要なときだけ Read: `commit-message-rule.md` / `branch-name-rule.md`

## レビュー観点（変更に応じて選択）

- **アーキテクチャ**: レイヤー境界・依存方向・適切な抽象
- **セキュリティ**: インジェクション、認可漏れ、秘密情報、入力検証
- **パフォーマンス**: N+1、不要再レンダー、インデックス、一括処理
- **保守性**: 命名、単一責任、DRY、既存パターンとの一貫
- **テスト**: 追加／更新、エッジ、実装詳細への過結合

## テンプレート骨格

```markdown
### 判定: {✅ Approve / ❌ Request Changes / ⚠️ Comment}

{判定理由の要約}

### 対象ファイル / スコープ

### チェック結果サマリー（該当カテゴリのみ）

| カテゴリ | 結果 |
| -------- | ---- |

### 重要度別の指摘（P0 / P1 / P2）

- **P0-1. …** — 箇所 / 現状 / 理由 / 推奨（改善例は任意）

### 集計

- P0: X / P1: Y / P2: Z

### 次のアクション

- **Must have**: P0 / P1
- **Nice to have**: P2

### （任意）良い点 / **反証できなかった点**（レビュー系は review-common に従い末尾必須。なければ「なし」）
```

該当がないセクションは省略可。
