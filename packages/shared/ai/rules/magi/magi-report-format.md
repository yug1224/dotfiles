# MAGI レポート出力フォーマット

`/magi` と `/review-pr-magi` が参照する共通スケルトン。コマンド本文にフォーマットを重複定義しない。

## 自己申告（`✅️:`）

`/magi` / `/review-pr-magi` 経由では **コマンドの ✅️ のみ**（本ルールの `✅️: magi-report-format` は出さない）。ルールを `@` / 明示 Read したときのみ本ルールの ✅️ を出す。一般規則は [CONVENTIONS.md](../../CONVENTIONS.md)「自己申告」。

## 松竹梅アクション（定義）

| 案             | 意味                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------- |
| **松（理想）** | 3 体の提言を統合。矛盾はトレードオフとして明示                                                       |
| **竹（標準）** | BALTHASAR-2 の段階的計画を中核に、他 2 体の提言を条件として付記。**最優先アクションはここから 1 件** |
| **梅（最小）** | CASPER-3 のリスク緩和を最優先し、最小限の前進のみ                                                    |

## 合議判定レポート（`/magi`）

```markdown
## MAGI System 判定レポート

### TL;DR

**MAGI 判定**: [APPROVE / CONDITIONAL / REJECT]（X対Y対Z）

- 各ユニットの判定一言 + **最優先アクション** 1件（竹から）

### 議題

（評価対象の要約）

### 各ユニット（MELCHIOR-1 / BALTHASAR-2 / CASPER-3）

確信度・一言・評価・根拠・条件・提言

### 合議結果

判定根拠（非全会一致時は少数意見を強調）+ 交差分析 + 松竹梅アクション（上記定義）
全会一致時は Devil's Advocate 注記。盲点・判定を覆す条件があれば記載。
```

## PR Review レポート（`/review-pr-magi`）

```markdown
## MAGI PR Review レポート

### TL;DR

**MAGI 判定**: [✅ Approve / ⚠️ Comment / ❌ Request Changes]（X対Y対Z）

- 各ユニットの判定一言 + **最優先アクション** 1件

### PR 概要

タイトル / ブランチ / 変更ファイル数 / CI

### 各ユニット（MELCHIOR-1 / BALTHASAR-2 / CASPER-3）

確信度・一言・評価・指摘事項（P0/P1/P2）

### 合議結果

判定根拠 + 統合指摘一覧（重複排除・最高 Priority 採用）+ 交差分析 + 次のアクション（Must/Nice）
全会一致時は Devil's Advocate 注記。盲点があれば記載。
```
